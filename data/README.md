# data/

Generated by `node scripts/merge-fodmap.mjs` from `research/*.json`. Do not hand-edit `fodmap.json`;
fix the research file (or add an override in the app) and re-run the merge.

## fodmap.json

`{ generated, count, foods: Food[] }`

| Field | Meaning |
|---|---|
| `id` | slug, stable key for user overrides |
| `name`, `aliases` | lowercase, US English; aliases include UK/AU names and plural forms |
| `category` | vegetable, fruit, grain, legume, nut-seed, dairy, protein, sweetener, beverage, alcohol, condiment, processed, herb-spice, additive, other |
| `fructans`, `gos`, `lactose`, `fructose`, `polyols` | `high` / `moderate` / `low` / `null` at a typical serving. `null` = not a source of that group or not stated |
| `overall` | worst of the five groups. `null` = untested (show as "?" in the UI, never as low) |
| `groupUnknown` | `true` when a source rated the food low/high without naming a group; `overall` was inferred from serving text |
| `tier` | `primary` = appears in a public rating list. `variant` = literature-only lab sample (e.g. "bread, wheat (spain, market mean)"); search these last |
| `polyolType` | sorbitol / mannitol / perseitol when known |
| `lowServing`, `moderateServing`, `highServing` | free text from the highest-priority source. "none (avoid)" means no low serve exists. "typical serve" means low but no gram limit published |
| `quantitative` | g per 100 g from literature when available, plus `servingG` used for the derivation |
| `confidence` | `high` = 3+ independent source families, `medium` = 2, `low` = 1 |
| `sourceFamilies`, `sources` | which research files and URLs contributed |
| `conflicts` | every cross-source disagreement, verbatim, so the UI can show a "sources disagree" marker |
| `notes` | per-source notes, prefixed with the family |

Priority when sources disagree: `monash-public` > `literature` > `clinical-handouts` > `open-datasets`,
tie-breaking toward the more cautious rating. Serving text prefers Monash public, then handouts; literature-derived
servings are used last because several were computed from abstract-only data.

## ingredient-keywords.json

253 substrings for scanning packaged-food ingredient lists: `{ keyword, group, rating, note }`. Includes explicit
`low` negation entries (e.g. "garlic infused oil", "lactose-free", "sourdough") that must be matched before their
high-rated parents. Monash's rule applies: onion, garlic, inulin, FOS and GOS are avoid regardless of list position;
polyols, fructose sweeteners and lactose depend on how far up the list they appear.

## SOURCES.md

Provenance report: source families, coverage by category and confidence, every conflicted food, open datasets
evaluated with license verdicts, and all URLs read.
